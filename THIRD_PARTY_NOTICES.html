天气与城市数据

天气和城市查询通过 HTTP 调用 Open-Meteo 服务，项目没有复制、打包或修改其服务端代码。

  • 天气与 API 数据：由 Open-Meteo 提供，适用 Creative Commons Attribution 4.0 International（CC BY 4.0）。官方许可说明要求在数据显示处提供署名和链接。导航台将数据整理为温度、天气描述、逐小时和逐日预报，包含温度取整及展示顺序调整。
  • 城市数据：Open-Meteo 的地理编码接口基于 GeoNames。GeoNames 数据适用 CC BY 4.0；导航台对候选地名做排序和去重。见 GeoNames 来源与许可。

数据许可与 API 服务使用条件分别适用。当前使用 Open-Meteo 的免费接口，该接口仅供非商业用途并有限额；商业产品、订阅或广告场景须按其服务条款另行安排合适的服务方案。项目代码采用 MIT，不能据此取得免费接口的商业使用权限。
